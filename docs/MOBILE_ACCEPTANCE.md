Scrollbar занимает 9–10 CSS px, поэтому documentElement.clientWidth меньше заданного viewport. На проверенных экранах scrollWidth == clientWidth. Это не исчерпывающий аудит доступности: touch, экранная клавиатура, landscape, 200% zoom и длительная работа на слабом телефоне ещё требуют проверки.
