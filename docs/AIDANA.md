# Планировщик и отчёт Айданы

**Интеграция 10 ноября:** модуль включён в основной `python scripts/start.py`; отдельная команда factory также работает. В общем сервере `aidana_plan_snapshots` хранится в `DATABASE_PATH` и включается в общий backup. Ниже сохранена исходная инструкция изолированного демо с отдельным PLAN_DATABASE_PATH. Актуальная схема общего API и согласование владельцев — [P0_INTEGRATION.md](P0_INTEGRATION.md).

Реализован пакет P0 Айданы: детерминированный rules_v1, четыре маршрута API, серверная проверка ручных изменений, неизменяемые снимки SQLite, JSON отчёта и CSV UTF-8 с BOM. Фронтенд, импорт и аналитика сравнения принадлежат другим участникам.

## Запуск и проверка

Python 3.10+; команды из корня проекта:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements-planner.txt
python -m unittest discover -s tests -v
python -m uvicorn planner.app:create_demo_app --factory --reload
```

Swagger: http://127.0.0.1:8000/docs. Демо доступно по `POST /api/datasets/demo`: ID `aidana-demo`, классы `7A`–`7D`, темы `t1`–`t6`. В нём 120 искусственных учеников, 1440 строк, 24 часа. Это фиксированный пример для проверки модуля Айданы, а не итоговый набор Тони. Веб-интерфейс не входит в этот запуск.

Путь снимков по умолчанию `data/aidana-plans.sqlite3`; изменить переменной `PLAN_DATABASE_PATH`. Хранить этот файл на постоянном диске и включить в резервное копирование. Не публиковать реальную базу в Git. Приложение MVP без авторизации предназначено для локального/закрытого запуска.

## Контракт для Дамира

| Метод | Путь | Назначение |
| --- | --- | --- |
| POST | `/api/datasets/{id}/plans/preview` | Пересчитать предложение без записи |
| POST | `/api/datasets/{id}/plans` | Пересчитать на сервере, проверить и сохранить; HTTP 201 |
| GET | `/api/plans/{plan_id}` | Неизменяемый снимок и данные отчёта |
| GET | `/api/plans/{plan_id}/export.csv` | Экспорт именно сохранённого варианта |

Минимальный запрос preview/save: `{"class_id":"7A"}`. Дополнительно:

```json
{
  "class_id": "7A",
  "test_versions": {"t1": "v1"},
  "constraints": {"t1": {"min_hours": 2, "max_hours": 6, "importance": 3, "is_locked": false}},
  "settings": {"target_pct": 70, "donor_pct": 80, "min_students": 10, "max_change": 2}
}
```

Только save принимает `hours_by_topic` (целые часы для всех тем) и `comment`. Без `hours_by_topic` сохраняется рекомендация. `current_hours` нельзя подменить запросом: они берутся из набора. Сумма, границы, блокировки и лимит проверяются повторно. Для ручных решений допускаются темы с малой выборкой, но автоматический перенос для них исключён, как в ТЗ.

Ответы-примеры находятся в `contracts/plan-*.json`. `items` содержит названия, показатели, границы, важность, текущие и предложенные часы, изменения и объяснения. Сохранённый item дополнительно содержит `recommended_hours`, `manually_modified`, `recommendation_reason`. Поле `recommendation_transfers` — переносы исходной рекомендации, не история ручного редактирования. При изменении настроек клиент должен повторить preview.

В снимке сохранены `source` (метаданные/источник), `is_demo`, `applied_filters`, `metrics`, `settings`, `algorithm_version`, `created_at` (UTC), `comment`, все строки и предупреждения. Нельзя заменять null нулём. Печать и отображение даты в UTC+5 реализуются клиентом. CSV защищает текстовые ячейки от выполнения формул в табличном редакторе.

## Подключение Бекзатом

Совместимость проверена с веткой `backend/bekzat`, доступной 9 ноября 2026. Её код в этот коммит не включён. После объединения серверной ветки:

```bash
# Использовать серверное окружение и зависимости команды.
python -m uvicorn planner.app:create_integrated_app --factory
```

Фабрика вызывает `backend.app.main.create_app()`, который уже включает роутер и на старте подключает снимки к серверной БД. Импорт, демонабор и фильтры остаются маршрутами Бекзата. Публичный деморежим скрывает снимки реальных наборов. Снимки используют отдельную таблицу, исходные таблицы Бекзата сохранены.

Входной адаптер использует `get_dataset`, `get_topics`, `load_results`. Он считает среднее итоговое только для выбранного класса и единой версии/шкалы. Несколько версий без выбора дают null и запрет автоматического переноса. Неизвестные класс, тема или выбранная версия отклоняются. Адаптер использует `analytics.topics.compute_topics`, поэтому правило версии и численные показатели совпадают с аналитикой Тони, включая входные тесты без post.
