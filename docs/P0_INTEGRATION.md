## Точный интерфейс для Дамира

Базовый URL локально: `http://127.0.0.1:8000`. Разрешены Origins `http://localhost:5173` и `http://127.0.0.1:5173`; другой домен задаётся в `CORS_ORIGINS`. JSON-запросы отправлять с `Content-Type: application/json`, для multipart boundary формирует браузер.

1. `POST /api/datasets/import?dry_run=true`: FormData с `results_file`, `curriculum_file`, `metadata` (JSON-строка). Показать counts/preview/warnings. Повтор с `dry_run=false` сохраняет данные и возвращает `dataset_id` (201 новый / 200 уже существующий).
2. `GET /api/datasets/{id}/filters`: использовать реальные IDs классов/тем/версий. ID `aidana-demo` и темы `t1`–`t6` принадлежат только изолированному демо; общий сервер выдаёт UUID и другие topic_id.
3. `POST /api/datasets/{id}/plans/preview`: минимально `{"class_id":"7A"}`. Необязательные поля: `test_versions: {topic_id: version}`, `constraints: {topic_id: {min_hours,max_hours,importance,is_locked}}`, `settings: {target_pct:70,donor_pct:80,min_students:10,max_change:2}`. Подробные типы/границы — в OpenAPI. План строится для одного класса; общий список `class_ids` сюда не передаётся.
4. `POST /api/datasets/{id}/plans`: те же поля, дополнительно `hours_by_topic` (полная карта целых часов по всем темам) и `comment`. Сервер заново считает и проверяет ограничения; preview не является токеном. 201 возвращает SavedPlan с `plan_id`. Повторное сохранение создаёт отдельный снимок — кнопку на время запроса блокировать.
5. `GET /api/plans/{plan_id}`: неизменяемый SavedPlan. Отрисовывать отчёт из этого ответа, не из текущих фильтров экрана. `source`, `applied_filters`, `metrics`, `items`, `settings`, `algorithm_version`, `created_at` и `comment` сохраняют контекст решения.
6. `GET /api/plans/{plan_id}/export.csv`: скачивание CSV UTF-8 с BOM, `Content-Disposition` доступен через CORS. JSON/CSV используют один сохранённый вариант.

`PlanPreview.items` содержит `current_hours`, `proposed_hours`, `delta`, `reason`, ограничения и показатели. SavedPlan дополнительно содержит `recommended_hours`, `recommendation_reason`, `manually_modified`. Переносы рекомендации в сохранённом ответе называются `recommendation_transfers`. `null` не превращать в 0. `is_demo` показывать пользователю; время хранится в UTC, отображение в UTC+5 — на клиенте.

Ошибки: `code`, `message`, `details`, `total_errors`; 404 — неизвестный/недоступный набор или план, 422 — неверные данные/ограничения, 503 — временная недоступность SQLite. В деморежиме импорт/restore запрещены, расчёт и сохранение планов разрешены только для демонаборов; чужие загруженные наборы и их снимки скрыты.

`GET /api/capabilities`: `plan_preview`, `plan_save`, `plan_report`, `plan_csv` = true; `analytics` и `textbook_comparison` = false до подключения Тони. Соответствующие страницы не должны показывать фиктивный результат или бесконечную загрузку.

## Контракт аналитики — требуется Тони

Из ТЗ: `GET /api/datasets/{id}/overview`, `/topics/{topic_id}`, `/comparison`. Фильтры `class_ids`, `textbook_ids` — повторяемые query-параметры; `test_version` — одна выбранная версия. Для comparison обязательны `topic_id`, `textbook_a`, `textbook_b`; дополнительно class_ids/test_version.

Машинный проект контракта: `contracts/analytics-p0.proposed.openapi.json`. Он НЕ включён в живую OpenAPI и не создаёт рабочих маршрутов. Пути и поля TopicMetrics взяты из ТЗ; оболочки ответов и enum статусов предложены для согласования Тони. Ответственный подтверждает или корректирует этот файл вместе с реальными схемами, примерами и APIRouter в своём PR. Бекзат не реализует алгоритмы Тони.

TopicMetrics: `topic_id`, `mean_post_pct`, `below_threshold_share` (0–1), `n_post`, `n_pairs`, `mean_pre_paired_pct`, `mean_post_paired_pct`, `mean_gain_pp`, `status`, `problem_topic`, `warnings`; для контроля сопоставимости предложены test_version/max_score. Пустая статистика — null, не ноль. Несовместимые версии не объединять. Comparable допускается по ТЗ при совпадении предмета, параллели, темы, периода, версии и шкалы, минимум 10 пар в каждой группе и разнице входного среднего ≤10 п.п.; пересечение учеников двух групп отклоняется. Разность приростов не доказывает причинного эффекта учебника.
