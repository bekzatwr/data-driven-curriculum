# Приёмка модуля Бекзата

Результат: backend v0.2.0 в ветке `backend/bekzat`, [PR №1](https://github.com/bekzatwr/data-driven-curriculum/pull/1). Модуль готов к проверке другим участником и подключению остальных частей. Слияние в `main` выполняется по командному процессу после review.

## Демонстрация за 3–5 минут

1. Выполнить `python scripts/start.py`, открыть `http://127.0.0.1:8000/docs`.
2. Показать `/api/health` и `/api/capabilities`: сервер, база, версия, доступные функции.
3. Выполнить `POST /api/datasets/demo`, скопировать `dataset_id`. Показать 1440 результатов и фильтры 4 классов / 6 тем.
4. Открыть `/api/datasets/{id}/quality`: 720 пар, полнота по классам и темам. Для пропусков использовать собственный валидный CSV с неполными pre/post.
5. Скачать `/api/datasets/{id}/package`. Передать JSON в `/api/datasets/restore` с `dry_run=true`: данные проверены, новый набор ещё не записан. После `dry_run=false` показать созданный набор; повтор сохраняет прежний ID. Перенесённое демо имеет тип `upload`, что ожидаемо.
6. Показать зелёные проверки PR и раздел HANDOFF с точками подключения команды. При необходимости выполнить backup-команду из BACKEND.md и показать `integrity: ok`.

## Условия передачи

- Команда запускает сервер и использует фактический `dataset_id` из ответа, не ID из файлов-примеров.
- Аналитика Тони и планировщик Айданы уже подключены к стандартному серверу в `analytics/toni`, PR №2. Дамир подключает frontend к действующим API.
- Серверный путь от импорта до отчёта проверяется автоматически. Для полного MVP остаётся интерфейс и его сквозная проверка.
- Внешний хостинг ещё не подключён: адрес и аккаунт не выбраны. Docker-развёртывание проверено в CI; публичный режим рассчитан на синтетические данные.

Код и инструкции в `backend/bekzat`, проверки — в PR №1. Модуль можно проверять и подключать; после готовности ваших частей проведём совместную интеграцию и развернём весь проект».
