## API нового модуля `collab/` (контракт)

Ошибки — общий формат `{code, message, details, total_errors}`.

### Комментарии
`GET /api/datasets/{dataset_id}/comments?target_type=&target_id=` → `{"items": [Comment], "total": n}` (новые сверху, до 500).

`POST /api/datasets/{dataset_id}/comments` → `201 Comment`
```json
{"target_type": "plan_topic", "target_id": "<plan_id>:fractions",
 "author_name": "Айгерим С.", "author_school": "Школа №12", "author_role": "teacher",
 "text": "Дробям нужен ещё час перед СОР"}
```
- `target_type`: `dataset | topic | textbook | class | teacher | plan | plan_topic`
- `author_role`: `teacher | methodist | admin` (ответы ИИ, сохранённые в обсуждение, — `ai`)
- Лимиты: имя 1–80, школа ≤ 120, текст 1–4000 символов. 404 — неизвестный набор.

`Comment`: `id, dataset_id, target_type, target_id, author_name, author_school, author_role, kind ("human"|"ai"), text, created_at (UTC)`.

### ИИ
`GET /api/ai/status` → `{"configured": true, "providers": ["groq", "gemini"], "models": {"groq": "llama-3.3-70b-versatile", "gemini": "gemini-3.5-flash-lite"}}`

`POST /api/datasets/{dataset_id}/ai/explain`
```json
{"kind": "comparison", "context": {"...": "уже рассчитанные показатели с экрана"}, "question": "необязательный вопрос методиста"}
```
- `kind`: `overview | topic | comparison | plan | teachers | comments`
- `context` ≤ 30 КБ JSON; персональные данные учеников не отправляются (только агрегаты).
- Ответ: `{"text": "markdown", "provider": "groq", "model": "...", "created_at": "..."}`
- 503 `AI_NOT_CONFIGURED` — нет ключей; 502 `AI_PROVIDER_ERROR` — оба провайдера не ответили.
