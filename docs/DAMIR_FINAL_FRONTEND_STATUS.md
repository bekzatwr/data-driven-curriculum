## D. Исправленные ошибки и расхождения

1. ИИ отправлял браузерные показатели, тексты и комментарии. По PR #6 это 422 `AI_CONTEXT_SELECTORS_ONLY`, теперь уходят только селекторы.
2. Поле вопроса к ИИ давало 422 `AI_FREE_TEXT_DISABLED`. Поле убрано.
3. Кнопка «В обсуждение» создавала комментарий с ролью `ai`. По PR #6 это 422, и это была бы подмена автора. Кнопка убрана.
4. Сводка обсуждения и пояснения ИИ по учителям давали 503 `AI_KIND_NOT_READY`. Убраны.
5. ИИ по несохранённому плану: сервер требует `plan_id`. Теперь ИИ показывается после сохранения.
6. Read-only не учитывался для плана и комментариев: кнопка активна, а сервер отвечает 403. Теперь интерфейс выключает действие заранее и объясняет почему.
7. Запрос к зависшему серверу мог грузиться бесконечно. Теперь предел времени и ошибка 408.
8. 429 без подсказки, когда можно повторить. Теперь обратный отсчёт по `Retry-After`.
9. Клиентские прототипы учителей и плана на период выглядели как готовые модули. Теперь скрыты до серверных API.
